# Demo of Sequential Workflow Designer for React

This project contains a simple demo of using the `sequential-workflow-designer-react` package.

## 🚀 How to Run?

1. Clone this repository.
2. Install dependencies: `yarn install`
3. Run the project: `yarn start`

## Build New Theme 
1. Put below commands in package.json >> script section.
    "build-themes": "devextreme build",
    "postinstall": "npm run build-themes"
2.  Run npm install.

3.  Note : It will override old theme if you do the changes.
