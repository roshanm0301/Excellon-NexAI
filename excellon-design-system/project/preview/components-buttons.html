Usage rules

  • One primary action per surface — never two side-by-side.
  • Destructive replaces primary on confirm dialogs.
  • Brand link is for inline navigation, not for confirming forms.
  • Use sentence-case for secondary / tertiary labels (Cancel, View details); title-case for primary (Save Changes, Add Vehicle).
